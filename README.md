# Final_CTF_PT_Report
Full PT report - https://github.com/shenhav123/Final_CTF_PT_Report/blob/main/Final_CTF_PT_report.pdf

As part of the final project requirements for the Cyber Security course at ECOM College, our team — three members of the Cyber Security Team, myself included — conducted a comprehensive Penetration Test covering both the infrastructure and the web application of the college, using a Black-Box testing approach, on August 4th, 2026, in Rishon LeZion, Israel. The assessment was carried out as part of a final CTF (Capture The Flag) task, in which the team was assigned the following objectives: (1) read the flag file located at /flag.txt, and (2) achieve privilege escalation and gain full control over the target system.

The engagement lasted seven days and was performed using industry-standard penetration testing methodologies and techniques. Throughout the assessment, realistic attack scenarios were simulated in order to evaluate the security posture of the tested environment against real-world cyber threats, and to demonstrate practical proficiency in identifying, analyzing, and validating security vulnerabilities within a controlled environment.

Upon completion of the assessment, seven (7) distinct security vulnerabilities were identified, including: Reflected XSS, Information Disclosure, Brute-Force, Broken Access Control, Local File Inclusion (LFI), and Remote Code Execution (RCE). It was determined that a potential attacker could achieve Remote Code Execution by deploying a web shell, in combination with additional exploitable misconfigurations present within the system. Chaining these vulnerabilities together would allow an attacker to gain full control over the target environment — a scenario that could result in significant reputational damage to the organization and expose both the organization and its clients to substantial information security risks.

The full report documents the methodology applied throughout the assessment, the vulnerabilities identified, supporting Proof of Concept (PoC) evidence, risk analysis based on the CVSS standard, and recommended remediation measures for each identified vulnerability. This report was prepared strictly for educational purposes, and reflects the security posture of the tested environment as of the time the assessment was conducted, as defined and approved by the ECOM College faculty. Accordingly, the findings may no longer be applicable should changes have been made to the target systems following the completion of the assessment.

During the OSINT / Reconnaissance phase of the assessment, specifically during the Subdomain Enumeration stage, the team made use of a dedicated Python-based tool developed by Or Aviv, one of my project partners. The tool, named Subdomain Max Enumerator and enables automated scanning and identification of subdomains associated with the target domain, DNS queries and records, TLS certification data of the target domain and defence technology enumeration. The use of this tool significantly assisted the team in mapping the target organization's attack surface more efficiently and comprehensively, thereby directly contributing to the reconnaissance and initial assessment phases of the penetration test.
